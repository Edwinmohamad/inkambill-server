# INKAMNET Control Center v1.8.0

- Ticket baru dan progress harian dapat menyertakan lampiran foto JPG/PNG/WEBP.
- Jadwal piket dapat upload bukti foto; upload bukti otomatis menandai status hadir.
- Menu pelanggan memiliki pusat Tindakan: detail, edit, pembayaran, cek pembayaran, rincian tagihan, WhatsApp, dan arsip aman.
- Kategori kas operasional yang terlihat di UI sepenuhnya manual. Kategori internal billing disembunyikan untuk menjaga jurnal pembayaran otomatis.
- PDF invoice dibuat ulang dengan layout invoice perusahaan: billed-to, metadata, service line, payment info, totals, status, payment history, legal footer.
- Storage ticket dan bukti piket dipertahankan oleh workflow auto-deploy.

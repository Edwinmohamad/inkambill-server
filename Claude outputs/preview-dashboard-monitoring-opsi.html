Yang baru perlu ditambah: Test Ping, Ganti SSID, dan Ganti Password Wi-Fi (perintah TR-069 tambahan ke ONT). Untuk MikroTik, koneksi REST API & data trafik interface juga sudah tersedia di backend — yang belum ada baru dashboard health+trafik seperti di atas. Untuk OLT, saya belum menemukan integrasi apa pun di kode — ini butuh info merek OLT kamu (Huawei/ZTE/VSOL/Fiberhome/dll.) untuk menentukan SNMP OID atau API yang cocok.
